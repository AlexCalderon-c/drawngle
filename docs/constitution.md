# Drawngle Constitution

1. **Language:** Code, comments, documentation, and commit messages must strictly be in English.
2. **Privacy:** User data, 3D assets, and search history remain 100% local; no cloud-based telemetry or storage of private data.
3. **Testing:** No feature or logic is considered complete without passing automated unit or integration tests.
4. **Architecture:** Maintain strict separation between UI (React), business logic (backend/orchestrator), and AI pipeline; avoid tight coupling.
5. **Specs:** Every feature requires a written specification/plan prior to implementation; code must reconcile with the approved plan.
6. **Efficiency:** UI/UX must prioritize art reference workflow speed; local AI processing must be optimized for background execution.
